# NFT Operations

Browse, purchase, and manage NFTs via OpenSea integration.

## Supported Chains

Base, Ethereum, Polygon

## Capabilities

- Search collections and check floor prices
- Execute purchases
- View holdings and transfer assets
- Participate in minting (Manifold, SeaDrop)

## Collection Name Resolution

Common abbreviations auto-map: "BAYC" → `boredapeyachtclub`, "Punks" → `cryptopunks`, etc.

## Prompt Examples

```
"Show me floor price for BAYC"
"Buy cheapest Pudgy Penguin under 5 ETH"
"Show my NFT portfolio"
"Transfer my CryptoPunk to vitalik.eth"
"What's minting on Base right now?"
```

## Chain Recommendations

| Chain | Best for |
|-------|---------|
| Ethereum | Premium blue-chips, established liquidity |
| Base | Emerging collections, minimal fees |
| Polygon | Gaming NFTs, frequent trading |

## Safety

- Verify collection authenticity via official channels
- Check OpenSea verification badge
- Compare price vs floor before buying
- Validate contract addresses match official sources
- Be cautious of suspiciously cheap deals
