# x402 Payment Gateway

**Service:** `services/x402/`  
**Runtime:** Node.js / Bun + PM2 (`ecosystem.config.cjs`)

---

## What It Is

Pay-per-use API gateway gated by Solana micropayments. Agents and external callers pay lamports to access endpoints. Payment verified on-chain before granting access.

---

## Key Endpoints

| Endpoint | File | Description |
|----------|------|-------------|
| `POST /prophecy` | `endpoints/prophecy_ghost.py` | Pattern Blue prophecy generation |
| `GET /health` | `index.js` | Health check |
| Agent routes | `agents.js` + `agents.json` | Per-agent routing table |

---

## Agent Routing

`agents.json.example` defines the routing table. Each agent entry specifies:
- Endpoint path
- Lamport cost
- Handler function in `agents.js`

---

## Settlement → Sigil Bridge

When payment confirmed → `SigilBridgeListener.on_settlement(event)`:

```python
event = SettlementEvent(
    signature="tx_sig",
    payer="wallet_address",
    amount_lamports=1000,
    endpoint="/prophecy",
    timestamp=1234567890.0,
)
await bridge_listener.on_settlement(event)
```

Sigil forged in `spaces/OuroborosSettlement/`. Logged to ManifoldMemory.

---

## Self-Replication

`services/x402/shards/self_replicate.py` — triggers shard creation on volatility/load spikes. Templates in `shards/templates/base_shard.json`.
